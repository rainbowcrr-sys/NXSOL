# The NX key

**The NX key is the Windows key.** It is the physical key between Ctrl and
Alt, the one with the flag on it. NX System calls it the NX key instead.

**It is not the N and X keys.** Pressing `N` then `X` does nothing. If you
are looking for a key labelled "NX" on a keyboard, there isn't one -- the
keyboard still says whatever the manufacturer printed.

---

## Why rename it

The key has had three names already: the hardware calls it the Windows key,
Linux and BSD call it Super, and macOS calls it Command. Every system renames
it, because what it does is defined by the operating system, not by the
plastic.

NX System calls it the NX key for the same reason it calls everything else
NX. The same physical key, a name that matches the system you are using.

---

## What it does

| chord | action |
|-------|--------|
| NX | open the start menu |
| NX + R | run -- the quick launch window |
| NX + I | open Settings |
| NX + D | show the desktop |
| NX + L | lock the screen |
| NX + E | open the file manager |
| NX + Alt | reach the power menu (see below) |

---

## Recovery mode

**NX + Alt**, then click the power icon on the lock screen or in the start
menu, and choose restart.

That boots into recovery. There are two kinds, deliberately different in
size:

| where | what you get |
|-------|-------------|
| built into the machine | a minimal rescue shell. Enough to repair a Vault file. Not a desktop. |
| on the installation USB | the complete maintenance environment |

The small one is small on purpose: it has to keep working when the main
system does not, so it does not depend on much.

---

## If your keyboard has no such key

Any key can be made the NX key in Settings under *Keyboard → NX key*. On a
laptop without one, `Ctrl + Esc` is the usual substitute.
