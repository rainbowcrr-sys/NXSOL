# 首次启动体验（OOBE）

OOBE 在装好的 NX System 第一次开机时跑一次。它不是安装器 —— 区别见 `installer.md`。

## 步骤

| # | 步骤 | 说明 |
|---|------|------|
| 1 | 语言 | 设定系统默认语言 |
| 2 | 键盘 | |
| 3 | 网络 | 可跳过 |
| 4 | 本地账户 | 没有在线登录这回事 |
| 5 | 隐私 | 见下 |
| 6 | "请不要关闭您的计算机" | 全屏背景板，跟 Windows 一致 |
| 7 | 欢迎动画 | 一次性的多语言"你好" |

### 隐私默认值

基础诊断**默认开启**，可以在这一屏关掉。其余 —— 详细使用统计、位置、远程崩溃报告 —— 默认关闭。每一项单独列出，而不是藏在一个总开关后面，这样选择是看得见的。

### 只有本地账户

没有在线账户。不是"可选"，不是"推荐"，是没有。这台机器的第一个用户是这台机器上的账户。

## 欢迎动画

设置应用完、账户建好之后，全屏背景板显示系统正在完成设置。然后播放欢迎动画，一次：

```
    hello -> 你好 -> привет -> こんにちは -> 你好 -> ...
```

每一个淡入、定格、淡出。下方：一个带向上箭头的圆圈，加上"向上滑动跳过"的提示，用当前显示的语言。

如果安装时选过语言，那个语言的问候排第一。序列仍然会轮到其它语言 —— 重点在于这台机器在第一次见到你的时候，用不止一种语言说过你好。

跳过了也不会跳过欢迎本身。它只是把轮播掐短，然后显示 `Welcome Use NX System!` 两秒。欢迎不可省，能省的是问候的长度。

动画不会再播第二次。完成时写一个标记文件。
