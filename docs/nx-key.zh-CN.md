# NX 键

**NX 键就是 Windows 键。** 是 Ctrl 和 Alt 之间那个物理按键，上面印着旗子那个。NX System 里改叫它 NX 键。

**它不是 N 键加 X 键。** 先按 N 再按 X 不会有任何反应。如果你在找键盘上印着"NX"的那个键——没有，键盘上印的还是厂家原本印的东西。

---

## 为什么要改名

这个键已经有三个名字了：硬件叫它 Windows 键，Linux 和 BSD 叫它 Super，macOS 叫它 Command。每个系统都给它改名，因为**它做什么由操作系统决定，不由那块塑料决定**。

NX System 叫它 NX 键，跟它把所有东西都叫 NX 是同一个道理。还是那个物理按键，换个跟当前系统对得上的名字。

---

## 它做什么

| 组合键 | 动作 |
|--------|------|
| NX | 打开开始菜单 |
| NX + R | 运行 —— 快速启动窗口 |
| NX + I | 打开设置 |
| NX + D | 显示桌面 |
| NX + L | 锁定屏幕 |
| NX + E | 打开文件管理器 |
| NX + Alt | 呼出电源菜单（见下） |

---

## 恢复模式

**NX + Alt**，然后在锁屏或开始菜单里点电源图标、选重启。

这会启动进入恢复。分两种，大小是故意不一样的：

| 在哪 | 你得到什么 |
|------|-----------|
| 电脑内置 | 最小救援 shell。够修一个 Vault 文件，不是桌面 |
| 安装 U 盘 | 完整的维护环境 |

内置的那个小是故意的：主系统坏掉的时候它还得能用，所以它不能依赖太多东西。

---

## 键盘上没有这个键

可以在 设置 → 键盘 → NX 键 里把任意键指定为 NX 键。没有这个键的笔记本上，通常用 `Ctrl + Esc` 代替。
